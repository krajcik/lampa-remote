# Lampa Remote

Работай через CLI и структурированные ответы. Пакет скилла содержит
[операционный справочник](references/operations.md): установка, команды, конфиг и ошибки.
Прочитай его при первом использовании; затем обращайся к нужному разделу при смене ветки задачи.

## Определи входы и доступные инструменты

1. Установи цель: установка, чтение/диагностика или конкретное изменение на TV.
   Разрешение на изменение бери из текущего поручения; при read-only сохраняй приложение и настройки.
2. Найди установленный `lampa` в PATH либо клон `krajcik/lampa-remote` с `dist/cli.js`.
   Для клона вызывай `node <путь-к-клону>/dist/cli.js`; путь получай из рабочего окружения или задания.
   Если установки нет, используй раздел "Установить" справочника и доступный каталог проекта.
3. Проверь `--version` и `--help`. Для установки нужны Node.js 22+, npm,
   ADB и конкретный авторизованный TV. Серийный номер получай из `adb devices -l` или задания.
   При нескольких устройствах выбери подтверждённый serial; адрес TV не зашит в скилл.

Готово: определены CLI, устройство, цель и допустимые действия.
Недоступный инструмент или неоднозначное устройство — конкретный недостающий вход, а не повод угадывать.

## Выбери ветку работы

- **Установка/обновление:** следуй разделу "Установить" справочника.
  URL из `install-url` — секрет; передавай его в настройку плагина из приватного файла,
  не вставляй в чат, логи или коммит. Закончи свежими `status` и `doctor` после загрузки плагина.
- **Чтение/диагностика:** начни с `doctor`, затем читай нужные `status`, `ui`, `settings get`, `input`, `player` или `logs`.
  `doctor` пассивен; для обычного чтения CLI сам поднимет мост, но не откроет Lampa.
  `APP_NOT_FOREGROUND` исправляй явным `app start` только в пределах поручения.
- **Изменение:** прочитай исходное состояние, выбери уникальную семантическую цель,
  отправь действие один раз и проверь условие через `wait` или новое чтение.
  Для временной пробы восстанови исходное значение и проверь повторное открытие.
- **Ошибка:** интерпретируй код и `error.outcome` по справочнику.
  При `outcome: "unknown"` сначала прочитай фактическое состояние; повтор мутации вслепую недопустим.

Для обычного выбора используй `action --text/--key/--section`.
Если нужен ID, получи свежий `ui`: последующий snapshot или смена элемента могут сделать ID устаревшим.
Отказ из-за неоднозначности требует уточнить цель, а не выбрать первый элемент.

## Проверь результат задачи

Успешная отправка действия не означает завершение загрузки.
Заверши после наблюдаемого результата: нужный controller/элемент/значение настройки,
либо подтверждённый ввод. Для текста различай `domWritten` и `appConfirmed`:
`false` или `null` не подтверждают принятие приложением.

Активная заставка Lampa видна в `screensaverActive`.
Чтение и служебное пробуждение сохраняют её; явная `key` сначала закрывает заставку
без движения нижележащего интерфейса. После этого снова прочитай UI перед следующим действием.

В результате назови выполненное действие, подтверждающее наблюдение и невыполненную часть.
Нативный внешний плеер и питание TV не входят в возможности этого плагина.
Скриншот нужен при визуальной неопределённости; JSON не подтверждает качество изображения или звук.
